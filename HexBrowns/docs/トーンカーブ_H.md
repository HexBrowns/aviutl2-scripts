# トーンカーブ_H

トラックバーの動き（時間制御のグラフなど）の形を、そのままトーンカーブにして色を変えるアニメーション効果です。
RGB 全体に掛けるカーブと、R・G・B 個別のカーブの 4 本を使えます。フィルタオブジェクトにも対応しているので、画面全体の色補正にも使えます。

- `Script/トーンカーブ_H.anm2`（v1.00）

第三者作の `トーンカーブ(時間制御).anm2`（こんにゃくねこ氏の Tonecurve_C）と同じ項目・同じ使い方のまま、処理を作り直したフォークです。
原作はそのまま残してあるので、両方が一覧に出ます。

### 原作との違い

- **階調が細かくなりました。** 原作は色を 256 段に丸めてからカーブを掛けていたので、暗部を持ち上げると段が出やすくなっていました（実機の比較で、同じ持ち上げの段の数が 17 → 53）
- **255 を超える明るさ（加算合成の光など）を切りません**
- 半透明の部分は、透明度を外した本来の色にカーブを掛けます。透明度は変えません
- 速くなりました（1080p で 1 フレーム 12.9ms → 6.5ms、実機の計測）
- フィルタオブジェクトに対応しました
- **項目名・範囲・初期値は原作と同じです。** `.aup2` の `effect.name=トーンカーブ(時間制御)` を `トーンカーブ_H` に書き換えると、カーブがそのまま読まれます（実機で確認）

## インストール

1. `Script\トーンカーブ_H.anm2` を配置する
2. AviUtl2 を再起動する
3. オブジェクトに「トーンカーブ_H」を追加する（HexScript の中）。画面全体に掛けるときはフィルタオブジェクトとして追加する

## 使い方

1. 色を変えたいオブジェクトに「トーンカーブ_H」を追加する
2. **RGB[0-255]** の始点を 0、終点を 255 にし、移動方法を「直線移動(時間制御)」にする。この時点ではカーブは直線で、見た目は変わらない
3. 時間制御のグラフを編集する。**グラフの形がそのままトーンカーブになる**（横軸の左端が暗部、右端が明部。縦軸が出力の明るさ）
4. 色ごとに曲げたいときは、**R[0-255]** **G[0-255]** **B[0-255]** で同じことをする

グラフを使わなくても、始点と終点だけで簡単な補正ができます（移動方法は「直線移動」のまま）。

| やりたいこと | 始点 | 終点 |
|---|---|---|
| 黒を浮かせる | 30 | 255 |
| 白を抑える | 0 | 220 |
| 明暗を反転する | 255 | 0 |

### カーブの決まり方

- 横軸の入力 0〜255 を、オブジェクトの**先頭フレームから最終フレームまでの時間**に読み替え、その時刻のトラックの値（0〜255）を出力にします
- **移動方法が「移動無し」のトラックは、値に関係なくそのチャンネルを変えません。** 値を 128 などにしただけでは何も起きません
- RGB のカーブを通してから、R・G・B それぞれのカーブを通します
- トラックの値は 0〜255 に収めてからカーブにします
- 入力が 0〜255 の外（加算合成の光など）のときは、カーブの端の値から傾き 1 で延ばします。直線のカーブなら入力のまま出ます

## パラメータ

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| RGB[0-255] | 0 ~ 255 | 0 | R・G・B の全部に掛けるカーブ。移動無しなら使わない |
| R[0-255] | 0 ~ 255 | 0 | 赤だけに掛けるカーブ。移動無しなら使わない |
| G[0-255] | 0 ~ 255 | 0 | 緑だけに掛けるカーブ。移動無しなら使わない |
| B[0-255] | 0 ~ 255 | 0 | 青だけに掛けるカーブ。移動無しなら使わない |

4 本とも「移動無し」のときは何もしません。

## 注意

- **カーブを時間で変化させることはできません。** トラックの時間変化をカーブの形に使っているためです
- 中間点の無いトラックなら、オブジェクトの長さを変えてもカーブは変わりません（実機で確認）
- 原作と同じく、毎フレーム 4 本のトラックの値を読み直します。カーブを編集すればすぐ反映されます
