# ロングシャドー_H

オブジェクトの形のまま、指定した方向へ長く伸びる影（ロングシャドー）を付けるアニメーション効果です。
影の色はグラデーションにでき、影の両辺を広げたり（拡散）絞ったり（収束）、影の縁をぼかしたりできます。

v2.2（`Script/ロングシャドー_H.anm2`）。第三者作の `LongShadow.anm2` の拡張版で、影の付け方と項目は同じまま、**拡散・収束**と**エッジぼかし**を足し、
項目名を日本語にしています。`LongShadow.anm2` はそのまま残してあるので、両方が一覧に出ます
（項目名が違うため、`LongShadow` で保存した設定はこちらへは引き継がれません）。

## インストール

1. `Script\ロングシャドー_H.anm2` を配置する
2. AviUtl2 を再起動する
3. オブジェクトのフィルタ効果に「ロングシャドー_H」を追加する（HexScript の中）

エッジぼかしの「分布」は、`Script\Basic_S.lua`（Basic_S に同梱）があるときだけ効きます。無いときは標準の「ぼかし」で代わりにぼかします。

## 使い方

1. 影を付けたいオブジェクト（テキスト・図形・画像）に「ロングシャドー_H」を追加する
2. **長さ** で影の長さ、**角度** で影の向きを決める（0 で右、90 で下）
3. **開始色** で影の色を決める。単色にするなら **グラデーション** を OFF にする
4. 必要なら **ぼかし** で影の縁を柔らかくする

### 例: フラットデザインの短い影

実制作で使っている設定です。

| 項目 | 値 |
|---|---|
| 長さ | 8 〜 24 |
| 角度 | 35 〜 45（右下） |
| 開始色 | 黒か、黒に近い灰（`000000` / `1d1d1d`） |
| グラデーション | OFF |
| ぼかし | 0（くっきり）か 8（分布はガウス分布） |
| 回転を補正 | ON |

初期値は「白 → 黒のグラデーション」なので、単色の影にするときはグラデーションを OFF にするのを忘れずに。

## パラメータ

### シャドウ

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 長さ | 0 ~ 4000 | 200 | 影の長さ（ピクセル）。0 なら何もしない |
| 角度 | -1280 ~ 1280 | 0 | 影の伸びる向き（度）。0 で右、正の値で時計回り（90 で下） |
| 不透明度 | 0 ~ 1 | 1 | 影の不透明度 |
| 開始色 | - | ffffff | 影の、オブジェクトに近い側の色 |
| グラデーション | ON / OFF | ON | ON なら開始色から終了色へ、影の先端に向かって色が変わる。OFF なら開始色の単色 |
| 終了色 | - | 000000 | 影の先端の色（グラデーションが ON のときだけ使う） |
| 距離で透明 | ON / OFF | OFF | ON なら影の先端に向かってだんだん透明になる |

### 拡散・収束

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 上辺 | -80 ~ 80 | 0 | 影の上側の辺の開き角（度）。正で外へ広がり（拡散）、負で内へ絞る（収束）。角度 0（影が右）なら画面の上側の辺 |
| 下辺 | -80 ~ 80 | 0 | 影の下側の辺の開き角（度）。符号の意味は上辺と同じ。角度 0 なら画面の下側の辺 |
| 角度対称 | ON / OFF | OFF | ON なら下辺を上辺と同じ値にする（下辺の値は使わない） |

- 上辺・下辺は影の向きと一緒に回ります。影の伸びる向きを見て左手側が上辺、右手側が下辺です（角度 90 で影が下へ伸びるときは、上辺が画面の右側、下辺が左側）
- v2.1 までは拡散（正の値）のときだけ上辺と下辺が逆に効いていました（上辺 30 で画面の下側が広がった）。v2.2 で直しました。収束（負の値）の向きは元から同じです
- 上辺・下辺がどちらも 0 以上（拡散）のときは、オブジェクトの各部分からそれぞれ扇形に影が広がります。
  離れた文字や部品も、それぞれ同じ向きに広がります
- どちらかが負（収束）のときは、オブジェクト全体を 1 つの台形として影を絞ります

### エッジぼかし

| 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| ぼかし | 0 ~ 100 | 0 | 影をぼかす量。元のオブジェクトはぼかさない |
| 分布 | 矩形分布 / 三角分布 / ガウス分布 | 三角分布 | ぼかしの掛かり方。`Basic_S.lua` が無いときは効かない |

### オプション

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 影のみ | ON / OFF | OFF | ON なら影だけを描き、元のオブジェクトを重ねない |
| 回転を補正 | ON / OFF | ON | ON ならオブジェクトの回転（Z 軸回転）を打ち消し、影の向きを画面基準に保つ。OFF ならオブジェクトと一緒に影の向きも回る |
| フラット | ON / OFF | OFF | 影の色を、標準の「グラデーション」効果で塗る（原作 LongShadow のフラット部分と同じ処理。原作者は Aodaruma 氏の FlatShadow に影響を受けたと書いている）。上辺・下辺のどちらかが 0 でないときは効かない |

## 注意

- 影の分だけオブジェクトの画像を広げます。元のオブジェクトの位置はずれません
- 長さや拡散が大きすぎて、画像が本体の最大サイズ（既定 16384 × 16384）を超えるときは、収まるように**影の長さを自動で縮めます**
- 上辺・下辺を動かしているときは「フラット」が効きません
