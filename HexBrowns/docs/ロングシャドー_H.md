# ロングシャドー_H

オブジェクトの形のまま、指定した方向へ長く伸びる影を付けるアニメーション効果です。
影の色はグラデーションにでき、影の両辺を広げたり絞ったり、影の縁をぼかしたりできます。

v2.3.1。ファイルは `Script/ロングシャドー_H.anm2` です。
第三者作の `LongShadow.anm2` の拡張版です。
影の付け方と項目は同じまま、**拡散・収束**と**エッジぼかし**を足し、項目名を日本語にしています。
`LongShadow.anm2` とは名称が違うため競合の心配は不要です。
項目名が違うため、`LongShadow` で保存した設定はこちらへは引き継がれません。

## インストール

1. `Script\ロングシャドー_H.anm2` を配置する。
2. 色空間を sRGB 以外にするときは、`EffectUtils_ColorSpace.lua` も `Script` フォルダの直下に置く。[HexScript](https://github.com/HexBrowns/HexScript) のzipに入っています。
3. AviUtl2を起動する。
4. オブジェクトのフィルタ効果に、HexScriptの中にある「ロングシャドー_H」を追加する。

エッジぼかしの「分布」は、Basic_Sに同梱の `Script\Basic_S.lua` があるときだけ効きます。
無いときは標準の「ぼかし」で代わりにぼかします。

`EffectUtils_ColorSpace.lua` が無いまま色空間を sRGB 以外にすると、スクリプトのエラーになります。

## 使い方

1. 影を付けたいオブジェクトに「ロングシャドー_H」を追加する。
2. **長さ** で影の長さ、**角度** で影の向きを決める。0 で右、90 で下を向く。
3. **開始色** で影の色を決める。単色にするなら **グラデーション** をOFFにする。
4. 必要なら **ぼかし** で影の縁を柔らかくする。

### 例: フラットデザインの短い影

実制作で使っている設定です。

| 項目 | 値 |
|---|---|
| 長さ | 8 〜 24 |
| 角度 | 35 〜 45（右下） |
| 開始色 | 黒か、黒に近い灰（`000000` / `1d1d1d`） |
| グラデーション | OFF |
| ぼかし | 0（くっきり）か 8（分布はガウス分布） |
| 回転を補正 | ON |

初期値は「白 → 黒のグラデーション」なので、単色の影にするときはグラデーションをOFFにするのを忘れずに。

## パラメータ

### シャドウ

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 長さ | 0 ~ 4000 px | 200 | 影の長さ。0 なら何もしない |
| 角度 | -1280 ~ 1280 度 | 0 | 影の伸びる向き。0 で右、正の値で時計回り。90 で下 |
| 不透明度 | 0 ~ 1 | 1 | 影の不透明度 |
| 開始色 | - | ffffff | 影の、オブジェクトに近い側の色 |
| グラデーション | ON / OFF | ON | ONなら開始色から終了色へ、影の先端に向かって色が変わる。OFFなら開始色の単色 |
| 終了色 | - | 000000 | 影の先端の色。グラデーションがONのときだけ使う |
| 色空間 | sRGB / リニア / Oklab / HSV / HSL / Lab / LCh / Oklch / HWB | sRGB | 開始色と終了色を混ぜる色空間。グラデーションがONのときだけ出る |
| 色相経路 | 短経路 / 長経路 | 短経路 | 色相を回す向き。色空間が HSV / HSL / LCh / Oklch / HWB のとき出る |
| 距離で透明 | ON / OFF | OFF | ONなら影の先端に向かってだんだん透明になる |

**色空間**は v2.3 で足しました。初期値の sRGB は v2.2 までと同じ色です。

| 色空間 | 向いている使い方 |
|---|---|
| sRGB | 今までと同じ混ぜ方 |
| リニア | 光の混ざり方に近い。明るい側が広がる |
| Oklab / Lab | 見た目の明るさが均等に変わる。補色の 2 色の中間がくすみにくい |
| HSV / HSL / HWB / LCh / Oklch | 色相を回して虹色にしたいとき。赤 → 青 を 短経路 にするとマゼンタを、長経路 にすると黄・緑・シアンを通る。Oklch・LCh は色相が回っても明るさがそろう |

白 → 黒 の影でも中ほどの明るさが変わります。影の中ほどは sRGB で約 128、Oklab で約 99 になり、Oklab の方が早く暗くなります。

### 拡散・収束

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 上辺 | -80 ~ 80 度 | 0 | 影の上側の辺の開き角。正で外へ広げて拡散、負で内へ絞って収束。角度 0 なら画面の上側の辺 |
| 下辺 | -80 ~ 80 度 | 0 | 影の下側の辺の開き角。符号の意味は上辺と同じ。角度 0 なら画面の下側の辺 |
| 角度対称 | ON / OFF | OFF | ONなら下辺を上辺と同じ値にする。下辺の値は使わない |

- 上辺・下辺は影の向きと一緒に回ります。影の伸びる向きを見て左手側が上辺、右手側が下辺です。
  角度 90 で影が下へ伸びるときは、上辺が画面の右側、下辺が左側です
- v2.1 までは拡散のときだけ上辺と下辺が逆に効いていました。v2.2 で直しました。収束の向きは元から同じです
- 上辺・下辺がどちらも 0 以上のときは、オブジェクトの各部分からそれぞれ扇形に影が広がります。
  離れた文字や部品も、それぞれ同じ向きに広がります
- どちらかが負のときは、オブジェクト全体を 1 つの台形として影を絞ります

### エッジぼかし

| 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| ぼかし | 0 ~ 100 | 0 | 影をぼかす量。元のオブジェクトはぼかさない |
| 分布 | 矩形分布 / 三角分布 / ガウス分布 | 三角分布 | ぼかしの掛かり方。`Basic_S.lua` が無いときは効かない |

### オプション

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 影のみ | ON / OFF | OFF | ONなら影だけを描き、元のオブジェクトを重ねない |
| 回転を補正 | ON / OFF | ON | ONならオブジェクトのZ軸回転を打ち消し、影の向きを画面基準に保つ。OFFならオブジェクトと一緒に影の向きも回る |
| フラット | ON / OFF | OFF | 影の色を、標準の「グラデーション」効果で塗る。原作LongShadowのフラット部分と同じ処理で、原作者はAodaruma氏のFlatShadowに影響を受けたと書いている。上辺・下辺のどちらかが 0 でないときは効かない |

## 注意

- 影の分だけオブジェクトの画像を広げます。元のオブジェクトの位置はずれません
- 長さや拡散が大きすぎて、画像が本体の最大サイズを超えるときは、収まるように**影の長さを自動で縮めます**
- 上辺・下辺を動かしているときは「フラット」が効きません
- **「フラット」では色空間が効きません。** フラットは影の色を標準の「グラデーション」で塗り直すので、標準の混ぜ方になります
- v2.3 で設定項目を足しました。ファイルを入れ替えたときは、AviUtl2の再起動が必要です
- 重さ（FHD・本体 2.1.13 で効果ぶんを実測、2026-10-13）: ロングシャドー_H は長さ 4000 で 1 フレーム約 200ms、上辺・下辺 80 で約 40ms と重い
